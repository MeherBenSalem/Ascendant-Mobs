# Contributing

Thanks for helping improve RPG Mob Leveling System.

## How to contribute

1. Fork the repository and create a branch from `main`.
2. Prefer small, focused changes with a clear purpose.
3. Match existing code style and MultiLoader layout (`1.20.1/` and `1.21.1/` workspaces).
4. Add or update tests when practical (common module JUnit).
5. Open a pull request describing what changed and why.

## Development

- Java 17 for `1.20.1` (Fabric + Forge)
- Java 21 for `1.21.1` (Fabric + NeoForge)
- Build a workspace with `./gradlew build` from `1.20.1/` or `1.21.1/`
- Shared logic lives in each workspace's `common` module
