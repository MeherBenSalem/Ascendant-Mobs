# Remnants: RPG Mobs 3.2.0

## New

- **Settings screen.** The difficulty and scaling settings can be changed in game: Mod Menu's config button on Fabric,
  the Config button in the Mods list on NeoForge and Forge, or `/remnants config` in a world. Eight sections: difficulty
  engine, levels and bands, health and damage per level, ranks, traits, rewards, Hunter's Moon and event nights, and the
  meter, nameplates and HUD. Every option shows its name and the description from the documentation, its default, its
  range and a reset button; numbers with a range at both ends get a slider.
- **The files stay the source of truth.** The screen writes the same JSON files in `config/remnant_mobs/`, through the
  code that reads them: comments and other keys are kept, values are written only as the mod would read them, and a
  file that is not valid JSON is never overwritten. Saving applies at once, like `/remnants reload`.
- **Who can change what.** With no world open, the screen edits your computer's files. In single player, and on a LAN
  world you host, you change the world's settings. On a server, server settings are read-only unless you are an
  operator: the server checks the permission and every value again before it writes, then reloads and updates every
  player. Your own settings (the difficulty meter, nameplates and HUD) are always yours to change, on any server.
- **Hide the difficulty meter** from the screen: Meter, nameplates and HUD → Show the meter. The option itself already
  existed (`progression.json → meter.hud`, read from your own copy); `meter.send_to_players` hides it for everyone on a
  server.
- **Every config option documented** in [docs/CONFIG.md](https://github.com/MeherBenSalem/Ascendant-Mobs/blob/main/docs/CONFIG.md): defaults, ranges and effects, how
  difficulty works, which keys control how strong mobs get, and recipes (slower or faster scaling, level caps, hiding the
  meter, an easier early game).

## Compatibility

- The screen uses new optional network channels: clients and servers without them still connect. On a 3.1 server the
  screen shows only your own settings, and `/remnants config` tells players without the mod where the files are.
- Mod Menu is not required; Fabric works the same without it.
- No config or save changes.
