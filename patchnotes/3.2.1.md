# Remnants: RPG Mobs 3.2.1

## Fixes

- **Health bars, levels and ranks on Epic Fight mobs, for real this time (Forge 1.20.1, NeoForge 1.21.1).** The 3.1.1
  fix listened for the render event Epic Fight cancels, at the same lowest priority Epic Fight uses on Forge 1.20.1.
  Which of the two ran first depended on the order mods loaded in, so in many packs the plate was still missing. Mobs
  that Epic Fight adds itself never reached that event at all. Plates are now drawn from the step every entity render
  goes through, whichever mod draws the mob, so they show on Epic Fight mobs in every pack and on every loader.

No gameplay, config or save changes.
