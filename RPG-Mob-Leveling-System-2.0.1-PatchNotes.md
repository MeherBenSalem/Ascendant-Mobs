# RPG Mob Leveling System v2.0.1

### Bug Fixes
* Ranged and special attacks from leveled mobs (arrows, Warden sonic boom, and other non-melee damage) now scale with level using the same attack-damage bonus ratio as melee.
* Melee damage is unchanged and is not double-scaled.

### Compatibility
* Minecraft 1.20.1 — Fabric, Forge
* Minecraft 1.21.1 — Fabric, NeoForge
* Drop-in replacement for 2.0.0

### Upgrade Notes
1. Install the matching loader jar for your Minecraft version.
2. No config migration required.
